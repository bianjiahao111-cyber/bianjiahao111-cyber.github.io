# 个人主页模板

这是一个可以直接放到 GitHub Pages 的静态网页，不需要安装依赖或运行构建命令。

## 发布前修改

1. 在 `index.html` 中替换「你的名字」、自我介绍、城市、领域和两个示例项目。
2. 将两处 `hello@example.com` 改为你的邮箱。
3. 如果有真实项目链接，可以给对应的作品卡片添加链接。

## GitHub Pages 设置

本网页使用 `bianjiahao111-cyber.github.io` 仓库，将 `index.html`、`styles.css` 和 `script.js` 放在仓库根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，再选择 `main` 分支和 `/ (root)` 文件夹。发布后网址是 `https://bianjiahao111-cyber.github.io/`。
